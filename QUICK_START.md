# 🚀 Быстрый старт

## За 5 минут до работающего бота!

### 1. Активируйте виртуальную среду

```powershell
.venv\Scripts\activate
```

### 2. Установите зависимости

```powershell
pip install -r requirements.txt
```

### 3. Получите токен бота

1. Откройте Telegram
2. Найдите бота [@BotFather](https://t.me/botfather)
3. Напишите `/newbot`
4. Следуйте инструкциям
5. Копируйте токен

### 4. Создайте файл .env

```powershell
copy .env.example .env
```

Отредактируйте `.env` и вставьте токен:

```
TELEGRAM_BOT_TOKEN=YOUR_TOKEN_HERE
```

### 5. Запустите бота

```powershell
python main.py
```

## ✅ Готово!

Откройте Telegram и найдите вашего бота. Нажмите `/start` и начинайте получать заказы! 🎉

```powershell

python manage_bookings.py all

# Бронирования на дату
python manage_bookings.py date 2026-09-01

# Свободные слоты
python manage_bookings.py check 2026-09-01

# Удалить бронирование
python manage_bookings.py delete 2026-09-01 10:00
```

## 🆘 Проблемы?

- **"ModuleNotFoundError: No module named 'aiogram'"**
  - Установите: `pip install -r requirements.txt`

- **"Invalid token"**
  - Проверьте, правильно ли вы скопировали токен в `.env`
  - Убедитесь, что нет пробелов в начале или конце

- **"Database is locked"**
  - Это нормально при наличии нескольких пользователей
  - SQLite автоматически обрабатывает конфликты
